Privacy Policy

Last updated: November 23, 2026

AUREL STUDIO is a creative research tool designed to help users organize visual references and develop original ideas.

1. Information We Access

If you connect a Pinterest account, the application may access authorized Pinterest account information, boards, and Pins through the Pinterest API.

Users may also select and upload images from their own devices.

2. Local Data Storage

In the current prototype, selected settings and board information may be stored in the browser. Uploaded images may be stored locally in the browser's IndexedDB database.

When Pinterest authentication is enabled, authentication information may be stored in a local file on the user's computer. Users should keep this file private.

3. Data Sharing

AUREL STUDIO does not currently operate a central cloud storage service. Pinterest authentication and API requests communicate with Pinterest as necessary.

We do not sell users' personal information.

4. AI Features

AI-based analysis and cloud processing are not currently enabled in this prototype. This policy will be updated before such features are introduced.

5. Third-Party Services

When using Pinterest integration, users are also subject to Pinterest's own terms and privacy policy.

6. Security

Users should protect their devices and keep authentication files and API credentials private. Do not share these files publicly.
